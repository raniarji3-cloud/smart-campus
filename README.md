# Smart Campus Management System

A full-stack Smart Campus Management System designed to automate and manage campus activities such as student attendance, face recognition authentication, announcements, geofencing, and dashboard management.

---

# Features

## Student Features
- Face Registration
- Face Recognition Attendance
- Geofence-Based Attendance Validation
- Student Dashboard
- Announcements Section
- Attendance Tracking
- Secure Login System

## Admin Features
- Admin Dashboard
- Manage Students
- Attendance Monitoring
- Announcement Management
- Geofence Management
- Face Data Management

# Installation

## Install Node Modules

```bash
npm install
```

## Create Virtual Environment

```bash
python -m venv faceenv
```

## Activate Virtual Environment (Windows)

```bash
faceenv\Scripts\activate
```

## Install Python Dependencies

```bash
pip install -r requirements.txt
```

---

# Run Project

## Start Node Server

```bash
node app.js
```

## Start Face Recognition Server

```bash
python face_server.py
```
